量子調和振動子のエネルギー計算機

零点エネルギーを含む 1 次元量子調和振動子のエネルギー準位を計算します。 入力単位を選択し、指定された条件内で 1 つの値を計算します。

入力値

SI 単位への換算後に 0 より大きい値

0 以上の整数

計算はこのブラウザー内で行います。1.2e-3 などの指数表記に対応しています。桁区切り文字は使わないでください。

計算結果

調和振動子のエネルギー Eₙ

—

値を入力し「計算する」を押してください。

公式

Eₙ = ℏω(n+1/2)

適用条件

ω>0、n は 0 以上の整数とします。平衡位置のポテンシャルが 0 の理想的な放物線ポテンシャルを仮定します。非調和性、減衰、相互作用、相対論的補正は考慮しません。入力は角周波数 ω で、Hz 単位の周波数 f とは ω=2πf の関係にあります。

表示値は浮動小数点数による近似値です。設計安全率や、入力されていない誤差要因は計算しません。
